# ADR-003: Adoptar un modelo SaaS B2B con suscripción por cuenta o cliente

- Estado: Aprobado
- Fecha: 2026-07-01
- Versión: 0.1.0

## Contexto
EmbryoApp necesita un modelo de negocio sostenible y escalable que se alinee con el valor entregado al cliente. Un modelo de licencia única o un proyecto esporádico no sería suficiente para sostener una plataforma de evolución continua.

## Decisión
Se adoptará un modelo SaaS B2B con suscripción mensual o anual por cuenta o cliente, con posibilidad de tarifas variables según volumen o número de programas activos.

## Justificación
Este modelo permite:
1. Generar ingresos recurrentes.
2. Alinear el negocio con la continuidad del producto.
3. Facilitar la expansión progresiva del servicio.
4. Reducir dependencia de proyectos puntuales.

## Consecuencias positivas
- Mejor previsibilidad financiera.
- Mayor alineación entre producto y negocio.
- Posibilidad de soporte continuo y mejora del servicio.

## Consecuencias negativas
- Requiere operaciones y soporte más consistentes.
- Exige alto nivel de calidad para retención del cliente.
- Implica considerar la experiencia de implementación y onboarding.

## Alternativas consideradas
- Modelo de licencia única.
- Modelo de servicios profesionales únicamente.
- Modelo freemium con alcance limitado.

## Decisión de seguimiento
La arquitectura, la estrategia de despliegue y la documentación operativa deben considerar un producto SaaS que requiera disponibilidad, seguridad y soporte continuo.
