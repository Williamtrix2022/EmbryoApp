# ADR-002: Enfocar el MVP en trazabilidad operativa y gestión de programas reproductivos

- Estado: Aprobado
- Fecha: 2026-07-01
- Versión: 0.1.0

## Contexto
EmbryoApp corre el riesgo de convertirse en una plataforma demasiado amplia si intenta cubrir todos los procesos agrícolas, financieros y operativos de una finca o clínica desde el inicio. Ese enfoque diluye el valor, aumenta la complejidad y dificulta la adopción comercial.

## Decisión
El MVP se enfocará exclusivamente en la gestión operativa y trazabilidad de programas reproductivos de transferencia de embriones, incluyendo programas, entidades, actividades clínicas, observaciones y seguimiento de estado.

## Justificación
Esta decisión permite:
1. Resolver un problema claro y repetitivo con alto valor para veterinarios y empresas de reproducción.
2. Construir un producto vendible y fácil de comprender.
3. Reducir riesgo técnico y de ejecución durante la primera etapa.
4. Mantener un producto más enfocado y sostenible.

## Consecuencias positivas
- Menor complejidad de desarrollo inicial.
- Mayor claridad para usuarios y equipo.
- Mejor posicionamiento comercial del producto.
- Menor riesgo de sobre-ingeniería.

## Consecuencias negativas
- El producto no cubrirá toda la operación completa de una finca o clínica en el MVP.
- Algunas necesidades futuras quedarán fuera del alcance inicial.
- Es posible que algunos usuarios esperen funciones adicionales desde el inicio.

## Alternativas consideradas
- Crear una plataforma integral de gestión agrícola completa.
- Incluir módulos financieros y comerciales desde el inicio.
- Desarrollar primero un sistema de seguimiento genérico y luego adaptarlo al dominio.

## Decisión de seguimiento
El alcance funcional del MVP, los requisitos, la experiencia de usuario y la arquitectura deben alinearse con este enfoque. Cualquier expansión más allá del dominio del MVP debe revisarse formalmente antes de incorporarse.
