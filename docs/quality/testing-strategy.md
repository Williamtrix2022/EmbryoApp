# Estrategia de calidad y pruebas — EmbryoApp

Versión: 0.1.0
Estado: En revisión

## 1. Objetivo
Definir la estrategia de pruebas y validación para asegurar calidad funcional, técnica y de experiencia en el MVP.

## 2. Enfoque propuesto
- Pruebas de aceptación para los casos de uso críticos.
- Pruebas de integración para API y persistencia.
- Pruebas de regresión para cambios recurrentes.
- Verificación de flujos offline y sincronización.

## 3. Tipos de pruebas recomendadas
- Pruebas unitarias
- Pruebas de integración
- Pruebas de sistema
- Pruebas manuales de UX
- Pruebas de sincronización y recuperación

## 4. Criterios de calidad
- Un caso de uso principal debe poder completarse sin errores críticos.
- La sincronización debe preservarse sin pérdida de datos.
- Los permisos deben aplicarse correctamente.

## 5. Recomendación de cierre
Este documento debe mantenerse alineado con los requisitos, el diseño de API y la estrategia operativa del producto.
