# UX y wireframes — EmbryoApp

Versión: 0.1.0
Estado: En revisión

## 1. Objetivo
Definir la experiencia de usuario del MVP para que el producto sea claro, útil y fácil de operar en contextos reales de trabajo.

## 2. Principios de UX
- Simplicidad por encima de la complejidad.
- Flujos claros para tareas críticas.
- Adaptación a uso móvil y escritorio.
- Minimizar pasos innecesarios.

## 3. Flujos principales

### 3.1 Crear un programa
1. Ingresar al sistema.
2. Seleccionar opción para crear programa.
3. Ingresar datos básicos.
4. Asociar entidades relevantes.
5. Programar actividades.
6. Guardar y revisar.

### 3.2 Actualizar un programa en campo
1. Abrir programa existente.
2. Añadir observación o actualizar estado.
3. Registrar actividad completada.
4. Sincronizar cuando haya conexión.

## 4. Estructura de pantallas sugerida
- Login
- Dashboard de programas
- Detalle de programa
- Gestión de entidades
- Agenda de actividades
- Perfil y configuración básica

## 5. Recomendación de cierre
Este documento debe actualizarse con wireframes y validaciones de usabilidad a medida que avance el diseño.
