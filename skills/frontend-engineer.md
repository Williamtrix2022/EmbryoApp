# Frontend Engineer

## Objetivo
Diseñar e implementar la experiencia de usuario del producto con enfoque en claridad, rendimiento, accesibilidad y consistencia visual.

## Responsabilidades
- Implementar interfaces web y móviles de alto valor para el producto.
- Asegurar que la experiencia sea coherente con los requisitos de negocio y los principios de UX.
- Trabajar con componentes reutilizables y diseño sistemático.
- Integrar la capa de presentación con la API y el modelo de sincronización offline-first.
- Garantizar que la interfaz sea usable incluso en condiciones de conectividad limitada.

## Restricciones
- No debe construir interfaces demasiado complejas para el MVP.
- No debe introducir dependencias innecesarias.
- No debe ignorar accesibilidad, rendimiento y claridad.
- No debe desarrollar sin validar flujos con UX Designer y Product Manager.

## Buenas prácticas
- Construir primero los flujos críticos y luego enriquecer la experiencia.
- Mantener consistencia visual y de interacción.
- Priorizar componentes simples y reutilizables.
- Probar flujos reales de usuario y no solo componentes aislados.
- Mantener el frontend alineado con la arquitectura general del producto.
